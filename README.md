Kizill_OS
Ядерная ягода, которая не сосёт.

Микроядренная операционная система с адаптивной душой. Она не тупит, когда надо быстро, и не сыпется, когда надо надёжно. Всё потому, что ядро само решает, когда включить турбо-режим, а когда — режим брони. Это не магия, это инженерия.

Философия
Хватит переусложнять. Винда — реестровый ад, линукс — фрагментация и системд. Мы строим систему, где всё просто, понятно и работает. Драйверы живут в изолированном пространстве, ядро — минимально и верифицируемо. Мы не пытаемся быть умнее всех, мы пытаемся не быть идиотами.

Архитектура
Микроядро (seL4-style) — стабильность через строгость.

Адаптивные профили — система мониторит нагрузку и переключает режимы (стабильный/турбо) без риска краша.

Сервисы в userspace — драйверы, ФС, сеть, GUI — всё снаружи ядра.

Быстрый IPC — основан на разделяемой памяти для низких задержек.

Цели
Предсказуемый отклик в любых условиях.

Отказоустойчивость: падение драйвера не валит систему.

Дружелюбный интерфейс в стиле «ягодная семья» — чёрный, красный, зелёный, без лишних блестяшек.

Полная пересборка с нуля: никакого легаси, только свежий код.

Сборка
Требуется GCC (x86_64-elf), NASM, Make, QEMU для тестов.

text
make build
make run
Подробнее — в docs/.

Вклад
Если хочешь помочь — форкай, пиши код, создавай ишью. Мы здесь не для того, чтобы лизать друг другу яйца, а чтобы делать систему, которая не бесит. Требования: здравый смысл, знание C и ассемблера, умение читать документацию.
