# Kizill_OS
Kizill_OS - микроядро с адаптивным переключением профилей (стабильный/турбо) на основе метрик, гибридный подход (seL4 верификация + Fluid скорость). Драйверы и сервисы изолированы в userspace. Цель предсказуемость, отказоустойчивость, отклик без компромиссов. Стиль ягодный минимализм (черный/красный/зеленый). Проект с нуля.
